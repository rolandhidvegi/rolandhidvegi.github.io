    Projects

    CanSat

    This is the PCB I am most proud of.
    It is the main PCB of the CanSat that participated in the 2023 edition of RCRC. It contains a lot of things tightly packed together, such as 2 synchronous step-down switch mode converters for 3.3V and 5V, a microcontroller, a LoRa Module, a microSD conector, and a bunch of sensors: temperature, humidity, pressure, a 6-axis IMU, particulate matter, CO2, as well as connectivity for a GPS module, a GSM module, a buzzer, a solar irradiance sensor, RS485 soil sensor, 4 analog inputs for SO2, NO2, CO, and UV light.

    Gas Sensors - CanSat

    This is the aditional PCB for the special electrochemical gas sensors used in the CanSat. They are highly sensitive and selective to the target gas, but are not easy to use.
    This PCB required an enormous amount of research and time to design.
    It contains 3 trans-impedance amplifiers (current-to-voltage converters) because these sensors have the output in current. Additionally, potentiostatic circuits maintain the correct bias potential between the sensing and reference electrodes.

    GroundStation - CanSat

    This is the receiving LoRa radio station for the CanSat.
    It contains a LoRa module, an Arduino Nano and a SMA connector for the 7 element Yagi antenna.

    Mini Sumo Robot

    This PCB design is lacking any special features; it has an Arduino, a DIY motor driver, 4 connectors for color sensors and 4 connectors for distance sensors.
    But it was manually etched from a copper plate with ferric chloride.

    Altium Project

    This PCB has a MPU-6050 3-axis accelerometer and gyroscope onboard and a connector for attaching an external SPI device on the SPI 1 interface. The connector pins can be reused as GPIO pins as well.
    3.3V for supplying the board are provided by an LDO regulator.

    STM32F405RGT6

    This is my first 4 layer PCB.
    I chose the STM32F405RGT6 microcontroller because it offers 1 Mbyte of flash memory.

    STM32F103C8T6

    This is the first PCB I ever designed.

    I must admit that I had a few abandoned attempts with EasyEDA before, but this is my first project that is technically viable and would work for sure. Although, this PCB was never physically manufactured.
