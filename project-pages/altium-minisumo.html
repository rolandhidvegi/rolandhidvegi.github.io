Altium - Minisumo Mechatronics Education Day 2024

Compact Competition PCB

Description

This Altium design is a compact minisumo robot control board created for the Mechatronics Education Day 2024. The board is optimized for motor control, sensor integration, and reliable power delivery in a compact chassis.

Key Features

  • Compact PCB layout for a minisumo robot
  • Motor driver and power distribution for high current loads
  • Sensor connectors for edge detection and distance sensing
  • Robust routing for return currents and power planes
  • Clear silkscreen and mounting holes for assembly

Design Highlights

The board layout prioritizes a short ground return path and carefully placed components. Power and signal traces are separated to reduce noise and ensure stable motor control.

Design Tools

EDA Software: Altium Designer
Project Focus: Mini Sumo competition electronics
Board Layers: 2-layer PCB

Learning Outcomes

This project improved my skills in compact PCB design, high-current routing, and the integration of sensors and actuators for mobile robotics.
