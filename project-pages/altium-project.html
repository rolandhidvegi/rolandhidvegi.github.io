Altium Project

STM32 Development Board

Description

This project represents my introduction to professional PCB design using Altium Designer. It demonstrates core skills in microcontroller design, power management, and peripheral interfacing.

Key Features

  • STM32 ARM Cortex-M microcontroller
  • MPU-6050 3-axis accelerometer and gyroscope
  • External SPI device connector
  • Flexible pin configuration (SPI pins reusable as GPIO)
  • Linear regulator for 3.3V power supply
  • Crystal oscillator for precise timing
  • Debug connector for in-circuit programming

Sensor Integration

The MPU-6050 is interfaced via I2C, providing 6-axis inertial measurement capability. This sensor is commonly used in motion tracking, robotics, and orientation sensing applications.

Power Management

The design includes a linear regulator (LDO) to provide clean 3.3V power to the microcontroller and sensors. Power filtering capacitors are strategically placed to minimize noise and ensure stable operation.

Design Tools

EDA Software: Altium Designer
Microcontroller: STM32 ARM Cortex-M series
IMU Sensor: MPU-6050
PCB Technology: 2-layer board

Learning Outcomes

This project provided valuable experience with professional PCB design software, schematic capture best practices, and understanding of embedded system design.
