Mini Sumo Robot

Robot Control Platform

Description

This PCB is designed for a Mini Sumo robot competing in robotic competitions. The design focuses on providing simple yet effective control for motor operation and sensor integration.

Key Features

  • Arduino microcontroller for autonomous control logic
  • DIY motor driver circuit for actuating two drive motors
  • 4 connectors for color sensors (edge detection)
  • 4 connectors for distance sensors (VL53L0X time-of-flight sensors)
  • Compact form factor suitable for robot integration

Manufacturing Process

One of the unique aspects of this project is that it was manually etched from a copper plate using ferric chloride. This hands-on approach provided valuable experience in traditional PCB fabrication techniques and demonstrated practical understanding of chemical etching processes.

Sensor Integration

The robot uses color sensors to detect the white arena boundary and prevent falling off the platform. Distance sensors provide obstacle detection and positioning information, allowing the robot to locate and engage opponents.

Motor Driver

The DIY motor driver uses discrete components to control bidirectional motor operation. This allows the robot to move forward, backward, and turn dynamically based on sensor inputs.

Tools & Techniques

Design: EasyEDA / KiCad
Manufacturing: Chemical etching with ferric chloride
Microcontroller: Arduino
Sensors: Color sensors, VL53L0X time-of-flight sensor
