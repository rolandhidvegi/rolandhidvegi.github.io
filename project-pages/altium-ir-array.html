Altium - IR Array Mechatronics Education Day 2024

Infrared Sensor Array

Description

This PCB supports an infrared sensor array for a line follower robot used in the Mechatronics Education Day 2024. It is designed to provide precise line detection across multiple sensors and robust signal distribution.

Key Features

  • 14-channel IR sensor array for line tracking
  • Stable reference and signal conditioning circuitry
  • Connector interface for the main control board
  • Compact form factor suitable for robot front mounting
  • Optimized sensor placement for consistent ground detection

Design Highlights

The layout places the IR emitters and receivers in a straight line with consistent spacing, while the board routing keeps analog signals isolated from digital noise.

Design Tools

EDA Software: Altium Designer
Project Focus: Line follower sensor array design
Board Layers: 2-layer PCB

Learning Outcomes

This design helped me improve sensor array layout, signal integrity, and PCB connector design for embedded robotics.
